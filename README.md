# 🎓 Student Life Management Dashboard

A beginner-friendly Python project that manages student information, academic performance, college fees, monthly expenses, eligibility checks, and progress tracking.

## 🚀 Features

- Store student details such as name, college, age, and course
- Calculate total marks and average marks
- Track annual fees and scholarships
- Calculate remaining college fees
- Track monthly income and expenses
- Calculate remaining monthly balance
- Check student eligibility using logical conditions
- Generate a progress score based on academic performance
- Display all information in a clean dashboard format

## 🧠 Python Concepts Used

- Variables
- `input()` and `print()`
- Integer conversion using `int()`
- Arithmetic operators
- Comparison operators
- Logical operators
- Boolean values
- `if / elif / else`
- f-strings

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python student_life_management_dashboard.py
```
